GStreamer plugin

Its is possible to optionally build a GStreamer plugin that can connects to the camera supported by Aravis.

The plugin implements a aravissrc source element. Here are the properties of the element:

The plugin must be installed to be usable by a GStreamer pipeline. Alternatively, the GST_PLUGIN_PATH environment variable allows to tell GStreamer where to find the Aravis plugin.

You can also test the uninstalled plugin using gst-aravis-launch andgst-aravis-inspect helper scripts build in builddir/gst/.

A simple pipeline would be:

gst-launch-1.0 aravissrc ! videoconvert ! autovideosink

It will connect to the first available camera and display the video in a window.

Using a format filter, you can select the video format and/or the framerate:

gst-launch-1.0 aravissrc ! video/x-raw,format=GRAY8,framerate=20/1 ! videoconvert ! autovideosink
